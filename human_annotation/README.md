# Human annotation

Both studies use a standalone HTML tool (`annotation_platform.html`, no server needed): the
annotator opens it in a browser, loads their CSV from `assignments/for_annotators/`, rates the
items and downloads `ratings_{ANN}.csv`, which goes in `ratings/`. Progress is saved in the
browser. `assignments/key.csv` maps the opaque item ids back to the pairs and is not sent to
the annotators. Sampling and assignment are seeded, so re-running them gives the same files.

The data of both studies (`samples/`, `assignments/` and `ratings/` in each study folder) is
not in the repository but on the Hugging Face Hub; download it into this folder (see the main
README). Run the scripts from the repository root. Results go to `results/human_annotation/`.

## Symmetry study (`symmetric/`)

Does a human rate "how well does B align with A" like "how well does A align with B"? The
rubric is the one of the judges' scoring prompt. 50 pairs (25 ValuePrism, 25 Habermas), one
per situation, stratified over the stance combination of the two opinions and taken from the
pairs the judges scored. Every annotator rates every pair in both orders (100 items): block 1
in a random order, block 2 with the other order, at least 20 items after the first.

```bash
python -m human_annotation.symmetric.sample_pairs
python -m human_annotation.symmetric.assign_annotators --n_annotators 5
python -m human_annotation.symmetric.compute_stability         # human PC, RS, asymmetry, agreement
python -m human_annotation.symmetric.paper_tables              # humans vs judges, LaTeX tables
python -m human_annotation.symmetric.human_directional_bias    # directional bias of humans vs judges
python plot_score_distribution.py --run_human                  # score distributions, humans vs judges
```

## Quality check of the generated opinions (`quality/`)

Do the ValuePrism opinions generated by Llama-3.3-70B keep the target stance, the value and
the explanation they were generated from (yes / no)? 150 opinions, 50 per stance, one per
situation, split between 3 annotators (50 each, no overlap).

```bash
python -m human_annotation.quality.sample_items
python -m human_annotation.quality.assign_annotators --n_annotators 3
python -m human_annotation.quality.compute_quality
```
